# 认证接口

> 基础路径: `/api/novel-auth`  
> 统一返回: `{ "code": 200, "message": "提示", "data": {} }`

## POST /login — 用户登录

**入参** (JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userName | String | 是 | 用户名 |
| password | String | 是 | 密码 |

**出参**: `Result<User>`  
**响应头**: `Authorization: Bearer <token>`

User 字段: id, userName, phone, email, avatar, type(0研发/1产品/2测试), status(0通过/1待审核/2失败), lastLoginTime

---

## POST /register — 用户注册

**入参**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userName | String | 是 | 用户名 |
| password | String | 是 | 密码 |
| phone | String | 否 | 手机号 |
| email | String | 否 | 邮箱 |
| type | Integer | 否 | 0=研发(默认审核通过), 1=产品, 2=测试(默认待审核) |

**出参**: `Result<User>`

---

## POST /fun-ai-login — 风行AI用户登录

**入参**: `{ "userName": "string", "password": "string" }`  
**出参**: `Result<FunAiUser>`  
**响应头**: `Authorization: Bearer <token>`

---

## GET /users — 分页查询用户 (权限: ROLE_0)

**入参** (Query):

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| page | Integer | 否 | 1 | 页码 |
| size | Integer | 否 | 10 | 每页条数 |
| keyword | String | 否 | - | 搜索关键词(用户ID或用户名) |

**出参**: `Result<Page<User>>`

---

## GET /users/approve/{userId} — 审核通过用户 (权限: ROLE_0)

**入参**: 路径参数 userId (Long)  
**出参**: `Result<User>`

---

## GET /users/delete/{userId} — 删除用户 (权限: ROLE_0)

**入参**: 路径参数 userId (Long)  
**出参**: `Result<String>`

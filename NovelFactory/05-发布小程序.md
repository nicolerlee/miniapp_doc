# 发布小程序

> 基础路径: `/api/novel-publish`

## GET /list — 获取已构建的小程序列表

**入参** (Query): testEnvironment (Boolean, 默认false)  
**出参**: `Result<List<NovelAppBuildInfoDTO>>`

NovelAppBuildInfoDTO:
```json
{
  "appName": "应用名",
  "platforms": [{
    "platformCode": "mp-weixin",
    "platformName": "微信小程序",
    "appId": "appid",
    "version": "1.0.0",
    "product": "产品名",
    "status": 1,
    "projectPath": "/path/to/project",
    "buildTime": "2025/01/01 12:00:00",
    "lastBuildTime": "2025-01-01 12:00:00"
  }]
}
```

---

## POST /publish — 发布小程序 (权限: ROLE_0, ROLE_1)

**入参** (JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| platformCode | String | 是 | 平台代码 |
| appId | String | 是 | 应用ID |
| projectPath | String | 是 | 项目路径 |
| version | String | 是 | 版本号 |
| log | String | 是 | 发布日志 |
| douyinAppToken | String | 抖音必填 | 抖音Token |
| kuaishouAppToken | String | 快手必填 | 快手Token |
| weixinAppToken | String | 微信必填 | 微信Token |
| baiduAppToken | String | 百度必填 | 百度Token |
| publishMode | String | 否 | 发布模式(preview=预览) |
| previewPath | String | 否 | 自定义预览路径 |
| previewQuery | String | 否 | 自定义预览参数 |
| previewScene | String | 否 | 自定义预览场景 |

**出参**: `Result<NovelAppPublishDTO>` 含 taskId

---

## POST /previewQrCode — 生成指定path预览码 (权限: ROLE_0, ROLE_1)

**入参** (JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| platformCode | String | 是 | 平台代码 |
| userId | Long | 是 | 用户ID |
| appId | String | 是 | 应用ID |
| projectPath | String | 是 | 项目路径 |
| path | String | 是 | 预览页面路径 |
| query | String | 是 | 查询参数 |
| scene | String | 是 | 场景值 |
| douyinAppToken | String | 条件 | 各平台Token |
| kuaishouAppToken | String | 条件 | |
| weixinAppToken | String | 条件 | |
| baiduAppToken | String | 条件 | |

**出参**: `Result<NovelAppPreviewQrCodeDTO>` 含 taskId

---

## POST /stop/{taskId} — 停止发布 (权限: ROLE_0, ROLE_1)

**入参**: 路径参数 taskId  
**出参**: `Result<String>`

---

## GET /qrcode/{taskId} — 获取发布二维码图片 (权限: ROLE_0, ROLE_1)

**入参**: 路径参数 taskId  
**出参**: PNG图片二进制流 (Content-Type: image/png)

---

## POST /batch-publish — 批量发布 (权限: ROLE_0, ROLE_1)

**入参** (JSON Body - BatchPublishRequest):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| publishParams | List\<Map\<String,String\>\> | 是 | 每项含platformCode/appId/projectPath/version/log及各平台token |
| description | String | 否 | 发布说明 |

**出参**: `{ "batchTaskId": "uuid", "taskIds": ["uuid1"] }`

---

## POST /batch-preview-test — 批量预览测试

**入参** (JSON Body - BatchPreviewRequest):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| previewParams | List\<Map\<String,String\>\> | 是 | 每项含platformCode/appId/projectPath/version/log |
| description | String | 否 | 说明 |
| testEnvironment | Boolean | 否 | 是否测试环境 |
| pageType | String | 否 | 页面类型(用于查询preview表获取path/query/scene) |

**出参**: `{ "batchTaskId": "uuid", "taskIds": ["uuid1"] }`

---

## POST /stop-batch/{batchTaskId} — 停止批量发布 (权限: ROLE_0, ROLE_1)

**入参**: 路径参数 batchTaskId  
**出参**: `Result<String>`

---

## GET /qrcode/batch/{batchTaskId}/{appId} — 获取批量发布二维码 (权限: ROLE_0, ROLE_1)

**入参**: 路径参数 batchTaskId, appId  
**出参**: PNG图片二进制流

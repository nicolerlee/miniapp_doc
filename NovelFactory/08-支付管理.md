# 支付管理

> 基础路径: `/api/novel-pay`  
> 支付类型(payType): normalPay, orderPay, renewPay, douzuanPay, imPay, wxVirtualPay, wxVirtualRenewPay

## POST /create — 创建支付配置 (权限: ROLE_0, ROLE_1)

**入参** (JSON Body - CreateAppPayRequest):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| appId | String | 是 | 应用ID |
| payType | String | 是 | 支付类型 |
| enabled | Boolean | 是 | 是否启用 |
| gatewayAndroid | Integer | 是 | 安卓支付网关 |
| gatewayIos | Integer | 是 | iOS支付网关 |

**出参**: `Result<AppPayWithConfigDTO>`

---

## GET /getAppPayByAppId — 获取支付配置

**入参** (Query): appId (String, 必填)  
**出参**: `Result<AppPayWithConfigDTO>`

AppPayWithConfigDTO 包含各支付类型:
```json
{
  "appId": "xxx",
  "normalPay": { "enabled": true, "gatewayAndroid": 1, "gatewayIos": 2 },
  "orderPay": null,
  "renewPay": null,
  "douzuanPay": null,
  "imPay": null,
  "wxVirtualPay": null,
  "wxVirtualRenewPay": null
}
```

---

## POST /updateAppPay — 更新支付配置 (权限: ROLE_0, ROLE_1)

**入参** (JSON Body - UpdateAppPayRequest):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| appId | String | 是 | 应用ID |
| payType | String | 是 | 支付类型 |
| enabled | Boolean | 是 | 是否启用 |
| gatewayAndroid | Integer | 是 | 安卓支付网关 |
| gatewayIos | Integer | 是 | iOS支付网关 |

**出参**: `Result<AppPayWithConfigDTO>`

---

## GET /deleteAppPayByAppIdAndType — 删除支付配置 (权限: ROLE_0, ROLE_1)

**入参** (Query): appId (String, 必填), payType (String, 必填)  
**出参**: `Result<String>`

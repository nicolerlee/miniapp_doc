# 任务队列

> 基础路径: `/api/task-queue`

## GET /statistics — 获取任务队列统计

**入参**: 无  
**出参**: `Result<Map>`

```json
{
  "prodPending": 0,
  "prodRunning": 0,
  "testPending": 0,
  "testRunning": 0,
  "totalPending": 0,
  "totalRunning": 0,
  "currentTaskId": "uuid或null"
}
```

---

## GET /debug — 获取队列调试信息

**入参**: 无  
**出参**: `Result<Map>` 含 allTasks(List), totalPending, totalRunning, currentTaskId

---

## POST /clear-running — 清理运行中的任务

**入参**: 无  
**出参**: `Result<String>` 返回清理数量

---

## POST /trigger — 手动触发队列处理

**入参**: 无  
**出参**: `Result<String>`

---

## GET /position — 获取任务在队列中的位置

**入参** (Query): taskId (String, 必填), testEnv (Boolean, 默认false)  
**出参**: `Result<Map<String, Integer>>`

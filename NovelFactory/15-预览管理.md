# 预览管理

> 基础路径: `/api/preview`

## POST / — 创建预览配置

**入参** (JSON Body - Preview):

| 字段 | 类型 | 说明 |
|------|------|------|
| appId | String | 应用ID |
| pageType | String | 页面类型 |
| path | String | 预览路径 |
| query | String | 查询参数 |
| scene | String | 场景值 |

**出参**: `Result<Preview>`  
**说明**: 同一appId+pageType组合不允许重复

---

## GET /{id} — 获取预览配置

**入参**: 路径参数 id (Integer)  
**出参**: `Result<Preview>`

---

## PUT /{id} — 更新预览配置

**入参**: 路径参数 id + JSON Body Preview  
**出参**: `Result<Preview>`

---

## DELETE /{id} — 删除预览配置

**入参**: 路径参数 id (Integer)  
**出参**: `Result<String>`

---

## GET / — 分页获取预览配置列表

**入参** (Query):

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| page | Integer | 否 | 1 | 页码 |
| size | Integer | 否 | 10 | 每页条数 |
| pageType | String | 否 | - | 页面类型筛选 |
| platform | String | 否 | - | 平台筛选 |
| appName | String | 否 | - | 应用名称筛选 |
| appid | String | 否 | - | 应用ID筛选 |
| keyword | String | 否 | - | 关键词搜索 |

**出参**: `Result<IPage<PreviewWithAppInfo>>`

---

## GET /listByAppId — 根据appId获取预览列表

**入参** (Query): appId, page(默认1), size(默认10), platform?, appName?  
**出参**: `Result<IPage<PreviewWithAppInfo>>`

---

## GET /listByPageType — 根据页面类型获取预览列表

**入参** (Query): pageType, page(默认1), size(默认10), platform?, appName?  
**出参**: `Result<IPage<PreviewWithAppInfo>>`

---

## GET /listByAppIdAndPageType — 根据appId和pageType获取

**入参** (Query): appId, pageType, page(默认1), size(默认10), platform?, appName?  
**出参**: `Result<IPage<PreviewWithAppInfo>>`

---

## DELETE /deleteByAppId/{appId} — 根据appId删除所有预览配置

**入参**: 路径参数 appId  
**出参**: `Result<String>`

---

## DELETE /deleteByPageType/{pageType} — 根据页面类型删除

**入参**: 路径参数 pageType  
**出参**: `Result<String>`

---

## GET /page-types — 获取页面类型选项

**入参**: 无  
**出参**: `Result<List<PageTypeOption>>` 用于前端下拉框

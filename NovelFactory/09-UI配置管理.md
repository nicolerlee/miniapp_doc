# UI配置管理

> 基础路径: `/api/novel-ui`

## POST /createUiConfig — 创建UI配置 (权限: ROLE_0, ROLE_1, ROLE_2)

**入参** (JSON Body - AppUIConfig):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| appId | String | 是 | 应用ID |
| homeCardStyle | Integer | 是 | 首页卡片样式 |
| payCardStyle | Integer | 是 | 支付卡片样式 |
| mainTheme | String | 是 | 主题色(如#FF6B35) |
| secondTheme | String | 是 | 第二主题色 |

**出参**: `Result<AppUIConfig>`

---

## POST /updateUiConfig — 更新UI配置 (权限: ROLE_0, ROLE_1, ROLE_2)

**入参**: AppUIConfig (同create)  
**出参**: `Result<AppUIConfig>`  
**说明**: 同时更新本地UI配置文件

---

## GET /deleteUiConfig — 删除UI配置 (权限: ROLE_0, ROLE_1, ROLE_2)

**入参** (Query): appid (String, 必填)  
**出参**: `Result<String>`

---

## GET /getUiConfig — 获取UI配置 (权限: ROLE_0, ROLE_1, ROLE_2)

**入参** (Query): appId (String, 必填)  
**出参**: `Result<AppUIConfig>`

---

## GET /getUiConfigByAppName — 根据应用名称获取UI配置列表 (权限: ROLE_0, ROLE_1, ROLE_2)

**入参** (Query): appName (String, 必填)  
**出参**: `Result<List<AppUIConfig>>` (所有同名应用的UI配置)

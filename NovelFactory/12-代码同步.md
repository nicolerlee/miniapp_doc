# 代码同步

> 基础路径: `/api/code-sync`  
> 所有接口同一时间只允许一个代码同步操作，并发请求返回429

## POST /pull — 从远程更新代码

**入参** (JSON Body, 可选):

| 字段 | 类型 | 说明 |
|------|------|------|
| branch | String | 分支名 |
| mode | String | 模式 |
| backup | Boolean | 是否备份 |
| testEnvironment | Boolean | 是否测试环境 |

**出参**: `Result<String>`

---

## POST /push — 上传代码到远程

**入参** (JSON Body, 可选):

| 字段 | 类型 | 说明 |
|------|------|------|
| commitMessage | String | 提交信息 |
| testEnvironment | Boolean | 是否测试环境 |

**出参**: `Result<String>`

---

## GET /branches — 获取分支列表

**入参** (Query): testEnvironment (Boolean, 必填)  
**出参**: `Result<List<String>>`

---

## GET /status — 获取代码同步状态

**入参** (Query): testEnvironment (Boolean, 必填)  
**出参**: `Result<Map>` 含 projectName, projectPath, branchName, workspaceStatus, remoteRepo, changes, aheadCount, behindCount

---

## GET /copy-status — 获取拷贝状态信息

**入参**: 无  
**出参**: `Result<Map>` 含 source 和 target 的 path/branch/status/changes

---

## POST /stash — 暂存修改

**入参**: `{ "branch": "string?", "testEnvironment": "boolean?" }`  
**出参**: `Result<String>`

---

## POST /restore-stash — 恢复暂存

**入参**: `{ "branch": "string", "stashKey": "string", "testEnvironment": "boolean?" }`  
**出参**: `Result<String>`

---

## POST /switch-branch — 切换分支

**入参**: `{ "branch": "string", "testEnvironment": "boolean?" }`  
**出参**: `Result<String>`

---

## GET /git-log — 获取Git提交历史

**入参** (Query): limit (Integer, 可选), testEnvironment (Boolean, 必填)  
**出参**: `Result<String>`

---

## POST /delete-dist — 删除指定目录

**入参**: `{ "path": "string", "testEnvironment": "boolean?" }`  
**出参**: `Result<String>`

---

## POST /copy-to-test — 拷贝代码到测试路径

**入参**: 无  
**出参**: `Result<String>`

---

## POST /install-npm — 安装npm包(异步)

**入参** (JSON Body, 可选):

| 字段 | 类型 | 说明 |
|------|------|------|
| force | Boolean | 是否强制安装 |
| clean | Boolean | 是否清理安装 |
| testEnvironment | Boolean | 是否测试环境 |

**出参**: `Result<String>` 返回taskId

---

## POST /cancel-install-npm — 取消npm安装

**入参**: `{ "taskId": "string" }`  
**出参**: `Result<String>`

# 应用通用配置

> 基础路径: `/api/novel-common`

## POST /createAppCommonConfig — 创建通用配置 (权限: ROLE_0, ROLE_1)

**入参** (JSON Body - AppCommonConfigDTO):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| appId | String | 是 | 应用ID |
| contact | String | 否 | 联系方式 |
| douyinImId | String | 否 | 抖音IM ID |
| kuaishouClientId | String | 否 | 快手Client ID |
| kuaishouClientSecret | String | 否 | 快手Client Secret |
| kuaishouAppToken | String | 否 | 快手App Token |
| weixinAppToken | String | 否 | 微信App Token |
| buildCode | String | 否 | 编译编码 |
| douyinAppToken | String | 否 | 抖音App Token |
| baiduAppToken | String | 否 | 百度App Token |
| readerLoginType | String | 否 | 阅读页登录类型 |
| mineLoginType | String | 否 | 我的页登录类型 |
| iaaMode | Boolean | 否 | 是否IAA模式 |
| iaaDialogStyle | Integer | 否 | IAA弹窗样式 |
| hidePayEntry | Boolean | 否 | 是否屏蔽付费入口 |
| hideScoreExchange | Boolean | 否 | 是否屏蔽移动积分兑换入口 |

**出参**: `Result<AppCommonConfig>`

---

## GET /getAppCommonConfig — 获取通用配置

**入参** (Query): appId (String, 必填)  
**出参**: `Result<AppCommonConfig>`

---

## GET /getAppCommonConfigByAppName — 根据应用名称获取通用配置

**入参** (Query): appName (String, 必填)  
**出参**: `Result<List<AppCommonConfig>>` (所有平台的配置)

---

## GET /deleteAppCommonConfig — 删除通用配置 (权限: ROLE_0, ROLE_1)

**入参** (Query): appId (String, 必填)  
**出参**: `Result<String>`

---

## POST /updateAppCommonConfig — 更新通用配置 (权限: ROLE_0, ROLE_1)

**入参**: AppCommonConfigDTO (同create)  
**出参**: `Result<AppCommonConfig>`  
**说明**: 同时更新本地配置文件

# 操作日志

> 基础路径: `/api/op-log`

## GET /queryAllOpByQuery — 分页查询操作记录

**入参** (Query):

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| query | String | 否 | - | 查询条件 |
| page | Integer | 否 | 1 | 页码 |
| size | Integer | 否 | 10 | 每页条数 |

**出参**: `Result<IPage<UserOpLogDTO>>`

UserOpLogDTO 字段: id, userId, userName, opType, opStatus, methodName, requestType, requestUrl, requestIp, requestParams, responseResult, updateTime

---

## GET /queryUserArchive — 获取用户重要操作记录 (权限: ROLE_0)

**入参** (Query):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| query | String | 否 | 查询关键字 |
| startTime | String | 否 | 起始时间(支持yyyy-MM-dd或yyyy-MM-dd HH:mm:ss) |
| endTime | String | 否 | 结束时间 |

**出参**: `Result<List<UserOpArchiveDTO>>`

UserOpArchiveDTO 字段: userId, userName, opType, opStatus, opName, requestUrl, requestParams, responseResult, updateTime(格式: xxxx年xx月xx日xx时xx分xx秒)

**说明**: 仅返回重要操作类型(opType: 2=INSERT, 3=UPDATE, 4=DELETE, 7=CODE_UPDATE)

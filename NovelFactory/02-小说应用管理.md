# 小说应用管理

> 基础路径: `/api/novel-apps`

## POST /create — 创建小说应用 (权限: ROLE_0, ROLE_1)

**入参** (JSON Body - NovelApp):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| appName | String | 是 | 应用名称 |
| platform | String | 是 | 平台: mp-weixin / mp-toutiao / mp-kuaishou / mp-baidu |
| appCode | String | 是 | 应用代码 |
| product | String | 否 | 产品名称 |
| customer | String | 否 | 客户名称 |
| appid | String | 是 | 应用ID(唯一) |
| tokenId | Integer | 否 | Token ID |
| cl | String | 否 | 客户端类型 |
| deliverId | String | 否 | deliver_id |
| bannerId | String | 否 | banner_id |
| version | String | 是 | 版本号(如1.0.0) |

**出参**: `Result<NovelApp>`

---

## GET /appLists — 获取按平台分组的应用列表

**入参**: 无  
**出参**: `Result<Map<String, List<NovelApp>>>` key为平台名

---

## GET /appListsWithBusinessTypeAndPublicSwitch — 含微剧信息的分组列表

**入参**: 无  
**出参**: `Result<Map<String, List<Map>>>` 每个app额外含:
- business_type, business_type_alias, business_type_enabled
- public_switch, public_switch_alias, public_switch_enabled

---

## GET /getByAppId — 根据appId获取应用

**入参**: appId (String, Query, 必填)  
**出参**: `Result<NovelApp>`

---

## POST /update — 修改应用基础信息 (权限: ROLE_0, ROLE_1, ROLE_2)

**入参**: NovelApp对象(同create)  
**出参**: `Result<NovelApp>`  
**说明**: 同时更新数据库和本地配置文件

---

## GET /delete — 删除应用 (权限: ROLE_0, ROLE_1)

**入参**: appId (String, Query, 必填)  
**出参**: `Result<String>`

---

## POST /updateVersion — 更新单个版本号 (权限: ROLE_0, ROLE_1, ROLE_2)

**入参**: `{ "appId": "string", "version": "string" }`  
**出参**: `Result<NovelApp>`

---

## POST /incrementVersions — 批量递增版本号 (权限: ROLE_0, ROLE_1, ROLE_2)

**入参**: `{ "appIds": ["appId1", "appId2"] }`  
**出参**: `Result<BatchUpdateVersionResponse>`

```json
{ "successCount": 2, "failedCount": 0, "details": [
  { "appId": "xxx", "version": "1.0.1", "success": true, "message": "版本号从 1.0.0 更新到 1.0.1" }
]}
```

**版本递增规则**: 末位非9则+1; 末位为9则中间位+1末位归零; 中间位也为9则首位+1中间位归零

---

## POST /batchUpdateVersion — 批量更新版本号 (权限: ROLE_0, ROLE_1, ROLE_2)

**入参**:
```json
{ "updates": [{ "appId": "string", "version": "string" }] }
```
**出参**: `Result<BatchUpdateVersionResponse>`

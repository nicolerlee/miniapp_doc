# 广告管理

> 基础路径: `/api/novel-ad`

## POST /appAd/create — 创建AppAd (权限: ROLE_0, ROLE_1)

**入参**: AppAd对象 (JSON Body)  
**出参**: `Result<AppAd>`

---

## GET /appAd/getAppAdByAppId — 获取AppAd

**入参** (Query): appId (String, 必填)  
**出参**: `Result<AppAdWithConfigDTO>`

AppAdWithConfigDTO 包含各类型广告配置:
- reward: { isRewardAdEnabled, rewardAdId, rewardCount }
- interstitial: { isInterstitialAdEnabled, interstitialAdId, interstitialCount }
- banner: { isBannerAdEnabled, bannerAdId }
- feed: { isFeedAdEnabled, feedAdId }

---

## GET /appAd/deleteAppAdByAppId — 删除AppAd (权限: ROLE_0, ROLE_1)

**入参** (Query): appId (String, 必填)  
**出参**: `Result<String>`

---

## POST /adConfig/create — 创建广告配置 (权限: ROLE_0, ROLE_1)

**入参**: AdConfig对象 (JSON Body)  
**出参**: `Result<AdConfig>`  
**说明**: 同时更新本地广告配置文件

---

## POST /adConfig/update — 更新广告配置 (权限: ROLE_0, ROLE_1)

**入参** (JSON Body - UpdateAdConfigRequest):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| adType | String | 是 | 广告类型 |
| appAdId | String | 是 | 应用广告ID |
| rewardAdId | String | 否 | 激励广告ID |
| rewardCount | Integer | 否 | 激励次数(>=0) |
| isRewardAdEnabled | Boolean | 否 | 激励广告启用 |
| interstitialAdId | String | 否 | 插屏广告ID |
| interstitialCount | Integer | 否 | 插屏次数(>=0) |
| isInterstitialAdEnabled | Boolean | 否 | 插屏广告启用 |
| bannerAdId | String | 否 | Banner广告ID |
| isBannerAdEnabled | Boolean | 否 | Banner广告启用 |
| feedAdId | String | 否 | Feed广告ID |
| isFeedAdEnabled | Boolean | 否 | Feed广告启用 |

**出参**: `Result<AdConfig>`

---

## GET /adConfig/deleteByAppAdIdAndType — 删除广告配置 (权限: ROLE_0, ROLE_1)

**入参** (Query): appAdId (Integer, 必填), adType (String, 必填)  
**出参**: `Result<String>`

# 构建小程序

> 基础路径: `/api/novel-build`

## POST /build — 构建小程序 (权限: ROLE_0, ROLE_1)

**入参** (Query): cmd (String, 必填, 构建命令)  
**出参**: `Result<String>` 返回taskId  
**说明**: 异步执行，通过WebSocket订阅构建日志

---

## GET /stop — 停止构建 (权限: ROLE_0, ROLE_1)

**入参** (Query): taskId (String, 必填)  
**出参**: `Result<String>`

---

## POST /batch-build — 批量构建 (权限: ROLE_0, ROLE_1)

**入参** (JSON Body - BatchBuildRequest):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| commands | List\<String\> | 是 | 构建命令列表 |
| douyinCombinedFlags | List\<Boolean\> | 否 | 抖音一次性构建标志 |
| prefetchCommands | List\<String\> | 否 | 预取命令列表 |
| description | String | 否 | 构建说明 |
| appIds | List\<String\> | 否 | 应用ID列表 |

**出参**:
```json
{ "code": 200, "data": { "batchTaskId": "uuid", "taskIds": ["uuid1", "uuid2"] } }
```

---

## POST /batch-build-test — 批量测试构建

**入参** (JSON Body - BatchBuildRequest): 同batch-build，额外字段:

| 字段 | 类型 | 说明 |
|------|------|------|
| businessTypes | List\<String\> | 业务类型列表(用于mock微剧) |
| publicSwitches | List\<String\> | 公共开关列表(用于mock微剧) |
| useNetworkMonitorTests | List\<Boolean\> | 启用网络监控标志 |
| mockWriteMode | String | mock写入方式: adData / adUrl |

**出参**: 同batch-build

---

## GET /stop-batch — 停止批量构建 (权限: ROLE_0, ROLE_1)

**入参** (Query): batchTaskId (String, 必填)  
**出参**: `Result<String>`

---

## GET /trigger-queue — 手动触发队列处理 (权限: ROLE_0, ROLE_1)

**入参**: 无  
**出参**: `Result<String>`

# 系统配置

> 基础路径: `/api/config`

## GET / — 获取系统配置

**入参**: 无  
**出参**: `Result<Map<String, String>>`

```json
{
  "build.workPath": "工作路径",
  "build.buildedPath": "构建输出路径",
  "build.testWorkPath": "测试工作路径",
  "build.testBuildedPath": "测试构建输出路径"
}
```

# 工具箱

> 基础路径: `/api/novel-toolbox`

## GET /app-upload-check — 发版前小程序检查 (权限: ROLE_0, ROLE_1)

**入参** (Query):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| appId | String | 是 | 小程序appid |
| projectPath | String | 否 | 项目路径 |

**出参**: `Result<AppUploadCheckDTO>`

```json
{
  "hasTestCode": false,
  "versionInfo": {
    "onlineVersion": "1.0.0",
    "currentVersion": "1.0.1"
  },
  "deliverInfo": {
    "deliverId": "xxx",
    "bannerId": "xxx"
  },
  "appPayWithConfig": { ... },
  "appAdWithConfig": { ... }
}
```

# 小说资源查找

> 基础路径: `/api/test`

## POST /channel-content — 获取频道内容

**入参** (JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| appId | Integer | 是 | 应用数据库ID |
| platform | String | 是 | 平台 |
| os | String | 是 | 操作系统 |
| channelMode | String | 是 | 频道模式(default/ad) |

**出参**: `Result<List<Map>>` 每项含 poster, cartoon_id, title

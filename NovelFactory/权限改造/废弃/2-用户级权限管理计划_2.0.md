## 一、拆分原则

原文同时包含：
- 后端权限模型设计
- Controller 接口映射
- 前端菜单/按钮控制方案

这三类内容放在一份文档里，评审和执行时会来回跳。现在拆分后：

- `2.1` 只负责后端：
  - 权限点怎么拆
  - 数据表怎么建
  - 注解怎么挂
  - 接口怎么映射
  - 白名单怎么处理

- `2.2` 只负责前端：
  - 登录后怎么取权限
  - 菜单怎么隐藏
  - 按钮怎么隐藏
  - 页面数据怎么按 `read / write` 控制
  - 权限管理页怎么接

## 二、阅读顺序

建议按这个顺序看：

1. 先看后端文档，确认权限模型和接口映射是否合理
2. 再看前端文档，确认页面与权限点的对应关系是否合理

## 三、当前口径

当前统一口径如下：

- 权限模型按 `资源 + 动作` 拆分
- 共 37 个权限点
- 共 104 个需鉴权接口
- 前端按 `read / write / run / stop / execute` 接入，`code-sync` 额外区分 `test / prod`

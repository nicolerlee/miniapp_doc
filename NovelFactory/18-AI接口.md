# AI Chat 接口

> 基础路径: `/api/ai`

## POST /chat — DashScope流式对话

**请求头**:

| 字段 | 必填 | 说明 |
|------|------|------|
| model | 否 | 模型名称(默认qwen-plus) |
| chatId | 否 | 会话ID(默认default-chat-id) |

**入参**: Body为纯文本 prompt (String)  
**出参**: SSE流 (Content-Type: text/event-stream)

# Fun AI 应用管理

> 基础路径: `/api/fun-ai/app`

## GET /create — 创建AI应用

**入参** (Query): userId (Long, 必填)  
**出参**: `Result<FunAiApp>`

FunAiApp 字段: id, userId, appName, appDescription, appType, appStatus(0空壳/1已上传/2部署中/3可访问/4部署失败/5禁用), accessUrl, lastDeployError

---

## GET /list — 获取用户应用列表

**入参** (Query): userId (Long, 必填)  
**出参**: `Result<List<FunAiApp>>`

---

## GET /info — 获取应用详情

**入参** (Query): userId (Long, 必填), appId (Long, 必填)  
**出参**: `Result<FunAiApp>` (appStatus=3时含accessUrl)

---

## GET /delete — 删除应用

**入参** (Query): userId (Long, 必填), appId (Long, 必填)  
**出参**: `Result<String>`

---

## POST /upload — 上传应用文件(zip)

**入参** (multipart/form-data):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| appId | Long | 是 | 应用ID |
| file | MultipartFile | 是 | zip压缩包 |

**出参**: `Result<String>` 返回文件保存路径

---

## POST /update-basic — 修改应用基础信息

**入参** (JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| appId | Long | 是 | 应用ID |
| appName | String | 否 | 应用名称(同用户下唯一) |
| appDescription | String | 否 | 应用描述 |
| appType | String | 否 | 应用类型 |

**出参**: `Result<FunAiApp>`

---

## POST /deploy — 部署应用

**入参** (JSON Body): `{ "userId": 1, "appId": 1 }`  
**出参**: `Result<FunAiAppDeployResponse>`  
**说明**: 仅appStatus=1(已上传)时允许部署; 异步执行npm install && npm run build; 前端轮询appInfo查看状态

---

# Fun AI 应用站点访问

## GET /fun-ai-app/{userId}/{appId}/**

**描述**: 访问已部署的AI应用静态资源  
**说明**: 仅appStatus=3(可访问)时可访问; 支持SPA路由回退到index.html

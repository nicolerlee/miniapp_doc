# 会员权益后跳转小程序逻辑梳理

> 适用项目：funNovel H5 小说阅读器  
> 覆盖平台：抖音H5（tth5）、快手H5（ksh5）、微信H5（wxh5）、百度H5（bdh5）

---

## 一、整体概述

H5 小说阅读器本质上是各平台（抖音/快手/微信）的 **引流载体**，核心目标是：

1. 用户在 H5 内免费阅读部分章节
2. 触发付费墙 → 用户购买会员或代币
3. 购买成功后，用户已有权益（全本免费），此时引导用户跳回对应平台的**小程序**继续阅读，体验更佳

跳转小程序的触发条件是 `media.isNovelHasRights === true`，即当前书籍所有章节均无需付费。

---

## 二、触发跳转的条件：isNovelHasRights

**定义位置**：`src/store/media.js`

```js
isNovelHasRights: (state) => {
  // 章节列表中没有任何需要付费的章节，则认为用户有完整权益
  return state._chapters.items?.filter(item => item.need_pay === '1').length <= 0 || false
}
```

**触发时机**：

- 用户购买会员（`event.type === 'member'`）或单本（`event.type === 'vod'`）后，调用 `refreshPlay()` 重新拉取章节数据
- 章节数据更新后，`isNovelHasRights` 变为 `true`
- `readerPage.vue` 中 `watch(isNovelHasRights)` 检测到变化，立即触发 `startCountdown()`

---

## 三、倒计时与自动跳转

**位置**：`src/pages/readerPage/readerPage.vue`

```
watch(isNovelHasRights)
    └── isNovelHasRights === true
        └── startCountdown()
            ├── countdown = 3（倒计时3秒）
            ├── 每秒 countdown--
            ├── UI 展示："3s 后自动跳转至【小程序】，体验更佳"
            └── countdown <= 0 → jumpToMiniapp()
```

**UI 展示条件**（同时满足）：
- `!media.need_pay`：当前章节不需要付费
- `media.isNovelHasRights`：全本有权益

用户也可以点击按钮主动触发 `jumpToMiniapp()`，无需等待倒计时。

## 四、jumpToMiniapp 跳转逻辑

**位置**：`src/pages/readerPage/readerPage.vue`

### 4.1 构造跳转参数

```js
// 基础参数：从 H5 入链时解析的透传参数（si、coopCode、clickid 等）
let params = AppConfig.h5JumpParams != '' ? Object.assign({}, AppConfig.h5JumpParams) : {}

// 追加当前阅读位置
params.cartoon_id = media.cartoon_id   // 书籍ID
params.num = media.sel.num             // 当前章节号

// 抖音额外需要第三方ID（抖音小程序侧的 book_id / chapter_id）
if (AppConfig.is_tth5) {
  params.book_id = media.third_cartoon_id
  params.chapter_id = media.third_chapter_id
}
```

**h5JumpParams 来源**：页面加载时由 `getMountConfig.js` 解析 URL query 参数，通过 `h5Jump.resolve()` 提取并写入 `AppConfig.h5JumpParams`。包含字段：`source`、`si`、`coopCode`、`clickid`、`adid`、`promotion_thirdad_id` 等投放透传参数。

### 4.2 各平台跳转方式

| 平台 | 跳转方式 | 目标页面 |
|------|---------|---------|
| 抖音H5（tth5） | 请求后端生成 schema，`window.location.href = schema` | `pages/novel_plugin/index` |
| 快手H5（ksh5） | 直接拼接 kwai schema，`window.location.href` | `pages/readerPage/readerPage` |
| 微信H5（wxh5） | 直接拼接 weixin schema，`window.location.href` | `pages/readerPage/readerPage` |
| 百度H5（bdh5） | 调用百度 H5 SDK `window.swanInvoke` | `pages/readerPage/readerPage` |

## 五、各平台详细跳转实现

### 5.1 抖音H5（tth5）

抖音不能直接拼 schema，需要通过后端接口动态生成。

```
1. 清理投放参数（不透传到小程序）：
   delete params.clickid / callback / adid / promotion_thirdad_id

2. 请求后端生成 schema：
   POST AppConfig.url.createschema
   Body: {
     business: getHostConfig('tt').cl,   // 抖音小程序的 cl 标识
     path: 'pages/novel_plugin/index',   // 目标页面路径
     query: JSON.stringify(params)       // 跳转参数（JSON字符串）
   }
   返回: { data: { schema: 'sslocal://miniapp?...' } }

3. 成功 → window.location.href = data.data.schema
   失败 → window.location.href = AppConfig.jumpHomeUrl（兜底首页 schema）
```

**兜底链接**：`AppConfig.jumpHomeUrl` 来自 `novelConfig[brand].tth5.tt_jump_home_url`，格式为 `sslocal://miniapp?ticket=v1_xxx`，每个品牌独立配置（见 `src/appConfig/localConfigs/novelConfig.js`）。

**后端接口**：`https://paps.funshion.com/v1/applet/createschema`

### 5.2 快手H5（ksh5）

直接拼接快手小程序 schema，无需请求后端。

```js
const ksAppid = getHostConfig('ks').appid   // 快手小程序 appid
const miniPath = 'pages/readerPage/readerPage'
const page = encodeURIComponent(`${miniPath}?${queryString}`)

url = `kwai://miniapp?appId=${ksAppid}&KSMP_source=011012&KSMP_internal_source=011012&path=${page}`
window.location.href = url
```

### 5.3 微信H5（wxh5）

直接拼接微信小程序 schema，无需请求后端。

```js
const wxAppid = getHostConfig('wx').appid   // 微信小程序 appid
const miniPath = 'pages/readerPage/readerPage'

url = `weixin://dl/business/?appid=${wxAppid}&path=${miniPath}&query=${encodeURIComponent(AppUtils.objToString(params))}&env_version=release`
window.location.href = url
```

### 5.4 百度H5（bdh5）

百度 H5 不是拼 schema，也不是写死 smartapps URL，而是调用百度提供的 H5 SDK `swanInvoke`。

```js
const bdAppKey = getHostConfig('bd')?.appKey || getHostConfig('bd')?.appid

if (window.swanInvoke) {
  window.swanInvoke({
    appKey: bdAppKey,
    path: 'pages/readerPage/readerPage',
    query: params
  })
}
```

**SDK 加载方式**：

- `src/main.js` 启动时调用 `autoLoadSDK(host)`
- 当 `host === 'bdh5'` 时，加载 `src/modules/base/sdkLoader.js`
- 远端脚本地址：`https://b.bdstatic.com/searchbox/icms/searchbox/js/swanInvoke.js`

**当前实现状态**：

1. **已实现**
   - `readerPage.vue` 已有 `AppConfig.is_bdh5` 分支
   - 已能带 `cartoon_id`、`num` 和 H5 入链透传参数调用 `window.swanInvoke`
   - 主入口已按 `bdh5` 自动加载百度 SDK

2. **未闭环**
   - 没有独立的百度跳转封装，逻辑直接写在 `readerPage.vue`，无法像支付跳转工具那样复用和单测
   - 仓库里没有百度跳转相关测试，当前只有快手/支付宝/抖音跳转测试
   - `bd` 端配置里只有 `appid`，没有显式 `appKey` 字段；代码靠 `appKey || appid` 兼容，语义不清晰
   - 失败场景只有 toast，没有降级方案；一旦 SDK 未加载或 `swanInvoke` 抛错，链路直接中断
   - 文档此前写成“硬编码 smartapps URL”，与当前代码不一致

## 六、完整流程图

```
用户购买会员/单本
    │
    ▼
payment-dialog / payment-view / payment-card
    └── 支付成功后 emit('event', { event: 'pay-success', type: 'member'/'vod' })
    │
    ▼
readerPage.onPayEvent()
    └── event.type === 'member' 或 'vod'
        └── refreshPlay()
            └── playApi.updateChaptersData()   ← 重新拉取章节列表
            └── playApi.loadAppointChapter()   ← 重新加载当前章节
    │
    ▼
章节数据更新，所有章节 need_pay === '0'
    │
    ▼
media.isNovelHasRights 变为 true
    │
    ▼
watch(isNovelHasRights) 触发
    └── startCountdown()
        ├── 展示倒计时 UI："3s 后自动跳转至【小程序】"
        └── 3秒后自动调用 jumpToMiniapp()
            │（用户也可点击按钮立即触发）
            ▼
        jumpToMiniapp()
            ├── 构造参数（h5JumpParams + cartoon_id + num）
            ├── tth5 → POST createschema → window.location.href = schema
            ├── ksh5 → window.location.href = kwai://miniapp?...
            ├── wxh5 → window.location.href = weixin://dl/business/?...
            └── bdh5 → window.swanInvoke({ appKey, path, query })
```

## 七、辅助 UI 展示

当 `isNovelHasRights === true` 时，除跳转按钮外，页面顶部还会展示引导文案：

```html
<!-- 顶部提示条 -->
<view v-if="media.isNovelHasRights" class="copyTitle" @click="copyTitle">
  <view>本文来自"{{AppConfig.app_name}}"小程序，{{getHostAppName()}}搜索"{{AppConfig.app_name}}"小程序</view>
  <view>点此复制书名，小程序内搜「{{书名前6字}}」</view>
```

点击可复制书名，方便用户在小程序内搜索。

## 九、注意事项

1. **抖音需动态生成 schema**：抖音小程序 schema 有时效性，不能硬编码，必须每次跳转前请求 `createschema` 接口生成。兜底的 `jumpHomeUrl` 是固定 ticket，只跳首页，不携带阅读位置。

2. **投放参数过滤**：抖音跳转时会删除 `clickid`、`adid`、`promotion_thirdad_id` 等投放参数，避免污染小程序侧的归因数据。

3. **isNovelHasRights 的判断时机**：该值依赖章节列表数据，只有 `updateChaptersData` 完成后才会更新。支付成功后必须先刷新章节数据，才能触发跳转流程。

4. **代币购买不触发跳转**：`event.type === 'token'` 时走代币购买单章/全本逻辑，不调用 `refreshPlay()`，因此不会触发 `isNovelHasRights` 变化，也不会跳转小程序。

5. **watch 设置了 immediate: true**：页面加载时如果用户已有权益（如 VIP 用户直接进入），会立即触发倒计时，无需等待支付。

6. **百度不是“未实现”，而是“实现不完整”**：当前链路已经能调用百度 H5 SDK 发起跳转，但缺少统一封装、测试覆盖、显式配置字段和失败兜底，工程化上仍未闭环。

# 渠道参数梳理

> 适用项目：funNovel H5 小说阅读器  
> 更新时间：2026-04-08

---

## 一、渠道类型与解析入口

渠道参数从 URL query 中解析，入口为 `src/modules/mod_mount/getMountConfig.js`，解析结果存入 `AppConfig.commonMountInfo`。

支持三种渠道类型：

| 渠道类型 | from 值 | 识别条件 | resolver 文件 |
|----------|---------|----------|---------------|
| 投流渠道 | `ad` | `coopCode == "ad"` | `resolver/adKey.js` |
| 橙星推 | `appfun` | `coop_client == "appfun"` | `resolver/funKey.js` |
| 推广计划 | `tuiguang` | 有 `coop_client` 但无 `coopCode` | `resolver/tuiguangKey.js` |

## 二、下单接口的渠道参数

下单接口为 `POST /v1/cartoon/pay`（`AppConfig.url.vipPayment`），渠道参数分以下几层传入。

### 2.1 请求 body 直接字段（addCommonMountPath）

> 代码位置：`src/hooks/usePay.js` → `addCommonMountPath()`

```
coop_client
coop_main
coop_expert
coop_appid
clicklocation（仅推广计划渠道 tuiguang）
```

### 2.2 BaseRequest 自动注入（baseADRequestParams）

> 代码位置：`src/modules/base/BaseRequest.js` → `baseADRequestParams()`

投流渠道（`from == 'ad'`）注入：

```
coop_main  = coopCode
coop_client = coopCode
coop_expert = popularizeId
coop_appid  = microapp_id
si          = coopCode
promotion_ad_id
promotion_code
promotion_thirdad_id
```

兜底套餐（H5 ad 渠道，si == doudiSi）注入：

```
coop_main = 'funshion'
coop_client = 'fun'
si
```

非投流渠道注入：

```
coop_main
coop_client
coop_expert
coop_appid
```

### 2.3 透传到 entrance 字段

> 代码位置：`src/hooks/usePay.js` → `addEntranceCommonMountParam()`

```
source, coop_client, coop_main, coop_code, coop_expert, coop_appid
ctime, si, osi, osi_expert, clicklocation
callback, promotion_ad_id, promotion_thirdad_id, promotion_code, promotion_pt
```

额外字段（按 promotion_code 条件追加）：
- `promotion_code == 'txgdt'`：追加 `third_account_id`、`third_set_id`、`third_maccount_id`
- `promotion_code == 'bdyx'`：追加 `third_maccount_id`

### 2.4 透传到 promotion 字段

> 代码位置：`src/hooks/usePay.js` → `makePayPromotionTouchuanParam()`

| 渠道 | promotion 内容 |
|------|---------------|
| 投流（ad / not_ad） | `{ coop: coopCode, expert: popularizeId, appid: microapp_id }` |
| 推广计划（tuiguang） | `{ coop: coop_main, expert: coop_expert, appid: coop_appid }` |
| 橙星推（appfun） | `{}` 传空，不透传 |

### 2.5 H5 端 params 字段（return_url 白名单）

> 代码位置：`src/hooks/usePay.js` → `makePayParams()`，仅 H5 非续费套餐生效

以下字段从当前 URL 中过滤后拼入 return_url：

```
cartoon_id, num, source, ctime, entrance, si
coopCode, microapp_id, popularizeId, clickid, callback
promotionid, promotion_ad_id, promotion_code, adid, promotion_thirdad_id, promotion_pt
coop_main, coop_client, coop_expert, coop_appid
```

> 注：快手H5（ksh5）会额外从白名单中移除 `callback`；微信H5（wxh5）普通套餐不传 params 字段。

## 三、上报接口的渠道参数

上报接口为 `https://stat.ibidian.com/lapp/{reportType}`，渠道参数通过 `addCommonParams` 和 `addMountParams` 两步注入。

### 3.1 公共字段（addCommonParams）

> 代码位置：`src/modules/mod_report/Report.js` → `addCommonParams()`

```
channel = 'novel'（固定值）
source  = 'h5'（H5 端固定）
promotion_ad_id（仅投流渠道）
promotion_code（仅投流渠道）
```

### 3.2 挂载字段（addMountParams → resolver.addParam）

> 代码位置：`src/modules/mod_report/Report.js` → `addMountParams()`  
> 最终由各 resolver 的 `addParam()` 决定实际字段

**投流渠道（adKey.js）：**

```
source, coopCode, coopMain, coopClient
popularizeId, microapp_id, osi
si, callback
promotion_ad_id, promotion_thirdad_id, promotion_code, promotion_pt
```

**推广计划（tuiguangKey.js）：**

```
source, entrance, coopCode='', coopMain, coopClient
popularizeId, microapp_id, osi='', clicklocation
si, callback
promotion_ad_id, promotion_thirdad_id, promotion_code, promotion_pt
```

**橙星推（funKey.js）：**

```
source, entrance, coopCode='', coopMain, coopClient
popularizeId, microapp_id, osi='', clicklocation
si, callback
promotion_ad_id, promotion_thirdad_id, promotion_code, promotion_pt
```
